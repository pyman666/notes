`module`是py运行时的概念，它本身是一个Python object，它保存在内存里，是Python级别的概念。
在Python中，module是组织单位，它自己独立构成一个命名空间。实际应用中，module对应的是py文件；

`package`是一种特殊的module，在Python中， package几乎和module有一样的功能，它只是多了一个path。
区分package跟module，是因为在操作系统层级，package 往往对应的是一个文件夹，一个文件夹里面可以有其他的文件、子文件夹，package里面可以有其他module、subpackage；

`import`是把文件系统里面的文件、文件夹变成一个Python的module、package的过程。

## 模块

模块名称：

- 直接运行py脚本，其名称就是`__main__`；
- 以模块的形式加载，其名称是由加载路径决定，`包名.子包名.模块名`，其中的“包名”被称为顶级名称；

```python
import sys
print(sys.path)

print(sys.__file__)  # 查看sys模块路径
dir(sys)  # 查看sys模块api

print(__name__)  # 查看当前模块名称，xxx.yyy.zzz或__main__
print(__package__)  # 查看当前包信息，如果为None，表示该模块是顶层模块
```

## 包

当我们从一个package里面调用东西的时候，该`__init__.py`文件内的代码会被首先执行**。**python3.3后的版本不加init文件也可以识别为package。

一般用`__init__.py`文件来批量导入和规范化导入：

```python
__all__ = ['foo', 'SomeClass'] 

from .module import *
```

如果想要使得某个package能够执行，可以在该package中加入`__main__.py`文件，然后在文件中插入行使相关功能的代码，运行package即可。

```python
print("run package")
```

包还支持一个特殊属性 `__path__` 。在包的 `__init__.py` 中的代码被执行前，该属性被初始化为一个只含一项的列表，该项是一个字符串，是`__init__.py`所在目录的名称。可以修改此变量；这样做会改变在此包中搜索模块和子包的方式。

```python
__path__.append(os.path.join(os.path.dirname(__file__), "utils"))
```

## import

```python
'''
p
├─__init__.py      # print("p")
└─sub_p
  ├─__init__.py    # print("sub_p")
  └─m.py           # a, b, c = 1, 2, 3
test.py  
'''

import p
# print(p.sub_p.m.a)  报错，没有引入 sub_p、m

import p.sub_p.m as m  # 第一次运行会打印 p、sub_p

from p.sub_p.m import a as aa, b as bb, c
```

### import *

对于`from xxx import *`的语句：

- 不能引入下划线开头的变量；
- 只能访问`__all__`里设置的变量；
- 把下划线开头的变量加入`__all__`也能被访问：

```python
'''
_a = 1
b = 2
c = 3

__all__ = ['_a', 'b']  # _a不加入__all__不能通过 from * 访问
'''

from m import *  # 能访问_a、b变量

from m import c  # 还是可以访问c变量
```

同理，可以在包内的`__init__.py`文件中控制包的访问范围：

```python
'''
__all__ = ['m1', 'm2'] 
'''

from p import *  # 只能访问m1、m2模块
```

### 导入过程

第一次导入时：

- 在当下命名空间中执行（被导入模块的）所有代码；
- 创建一个模块对象，将模块内所有顶级变量以属性的形式绑定到模块对象；
- 在import的位置，引入import后面的变量名到当前到命名空间；

第二次导入时：

- （只有上述第3步）在import的位置，引入import后面的变量名到当前到命名空间；
 
### 查找顺序

第一次导入时：`builtin` → `sys.path`（按顺序，找到就不往下了）；  
第二次导入时：从已加载的模块中找`sys.modules`；  

#### builtin

```python
import builtins

builtins.print("hello world")

dir(builtins)  # py3，查看内置模块
## dir(__builtin__)  # py2
```

#### sys.path

`sys.path`构成：

- 当前目录；
- 环境变量`PYTHONPATH`中指定的路径列表；
- 特定路径下的`.pth`文件中的文件路径列表；
- python安装路径的`lib`库；

追加路径的方式：

- 直接修改`sys.path`值（只作用于当前文件，注意优先级）；
- 修改环境变量`PYTHONPATH`（只在shell中有效）；
- 添加`.pth`文件；
 
```python
import sys

sys.path.append("C:/test.py")

import test
```

## 导入场景

### 包内导入 ★

包内的模块导入包内的模块称为包内导入，可以分为：

- 绝对导入：参照`sys.path`进行路径检索；
- 相对导入：使用`.`来指代相对路径；

使用建议：

- 包内导入：相对导入；
- 包外导入：绝对导入；
 
```python
'''
pkg/
    __init__.py
    sub_pkg1/
        __init__.py
        moduleX.py
        moduleY.py
    sub_pkg2/
        __init__.py
        moduleZ.py
    moduleA.py
'''

from . import moduleY

from .moduleY import spam as ham

from ..sub_pkg1 import moduleY
from ..sub_pkg2.moduleZ import eggs

from ..moduleA import foo
```

> 每一个relative import，都是先找到它的absolute import，然后再import。

简单来说，就是在相对导入里面，一个模块的位置是由该模块的 `__name__` 属性来确定，如果该属性值不包含任何包的信息，则把当前模块视为顶层模块。
在模块里可通过属性 `__package__` 获取自身的包信息，即该模块所在包的结构，诸如 `xxx`、`xxx.yyy.zzz`等形式，第一个节点就是顶层包，如果 `__package__` 为 `None` 表示该模块是顶层模块。

单独运行一个py文件时：

- 会将当前文件所在的目录添加到`sys.path`，之后`sys.path`的内容已经确定；
- 文件`__name__`为`__main__`，`__package__`为`None`，为顶层执行文件，不能使用相对导入；

### 局部导入

有时候在局部import可以节约资源、提高效率：

```python
def foo():
    import m  # 若foo没有使用，就不会import
    print(m.name)
```

### 覆盖导入

应避免使用覆盖导入。

当自己的模块名与内置模块重名时，可以使用`from x import xx` 来强制指定使用自己的模块，否则会被内置模块覆盖：

```python
import sys  # 内置

from my_pkg import sys  # 个人
```

### 循环导入

应避免使用循环导入。

a中导入b，b中导入a，可能会引起代码重复执行、或者变量未定义等问题：

```python
# name = 'a'  # 重复打印

import b
print(b.name)

name = 'a'  # 报错
```

```python
# name = 'b'

import a
print(a.name)

name = 'b'
```

### 可选导入

a、b模块功能相似，优先导入a，不存在则导入b：

```python
try:
    import a as m
except ModuleNotFoundError:
    import b as m

print(m.name)
```
