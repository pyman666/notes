## 迭代器

迭代器（iterator）需实现`__next__`方法，可迭代对象（iterable）需实现`__iter__`方法，官方建议迭代器也实现`__iter__`使得迭代器也是可迭代对象（可在for循环等使用）。

> 迭代器是有状态的，迭代这个行为需要在迭代器上来做，所以需要实现next，而可迭代对象是一个容器，对一个可迭代容器进行for循环隐式返回了一个这个容器上的迭代器（也就是指针），容器上需要定义iter方法来返回指针，指针需要实现next

> iterable是个容器，可以提供iterator，可以理解为完整的链表或者链表的表头；iterator是一个可以指向下一个对象的对象，可以理解为链表的一个单元；两者结合弥补了python不能用指针的缺陷，非常适合在链表这种数据结构中使用；为什么iterator最好也是iterable，是因为这样可以使得每一个子链都可以被调用

```python
class NodeIter:
    def __init__(self, node):
        self.curr_node = node

    def __next__(self):
        if self.curr_node is None:
            raise StopIteration
        node, self.curr_node = self.curr_node, self.curr_node.next
        return node
    
    def __iter__(self):
        return self

class Node:
    def __init__(self, name):
        self.name = name
        self.next = None

    def __iter__(self):
        return NodeIter(self)

n1 = Node("node1")
n2 = Node("node2")
n3 = Node("node3")
n1.next = n2
n2.next = n3

for node in n1:
    print(node.name)

for node in iter(n1):  # 获取n1的迭代器
    print(node.name)
```

### yield

有`yield`关键字的函数就是**生成器函数**，生成器函数不返回值，而返回一个**生成器对象**，对生成器对象使用`next`函数时，才开始真正运行函数本体。

生成器函数的`return`等价于`raise StopIteration`，使用`next`函数时，`return`的值不会返回，只会返回`yield`，`return`的值只能在`catch StopIteration`时获取。

> 生成器是一种特殊的迭代器，对于使用者感知较少。异同：迭代器把迭代状态保存在对象里，生成器把迭代对象保存在frame（栈桢）里

```python
def gen(n):  # 生成器函数
    while n > 0:
        yield n  
        n -= 1
    return  # 可不写，等价于return None、raise StopIteration

g = gen(5)  # 生成器对象
first = next(g)

for i in g:
    print(i)
```

迭代器用例改进：

```python
class Node:
    def __init__(self, name):
        self.name = name
        self.next = None

    def __iter__(self):
        node = self
        while node is not None:
            yield node
            node = node.next
```

### send

generator因为是iterator，所以支持`next`函数，这个很好理解。但是generator有一些自己特有的方法，`send`方法，`throw`方法和`close`方法。

![](https://pic3.zhimg.com/v2-fdd7e44b889f014f5be86131b92ff30e_r.jpg)

> `next(g) 等价于 g.send(None)`，for循环相当于不停next(g)，即不停send(None)

```python
def gen(n):
    while n > 0:
        temp = yield n
        if temp is not None:
            n = temp
        n -= 1

def gen(n):
    while n > 0:
        yield n  # 未接收yield表达式的值，不论send什么都相当于send(None)
        n -= 1

g = gen(5)
first = next(g)  # 启动生成器，等价于 first = g.send(None)
print(f"first: {first}")
print(f"send: {g.send(10)}")  # 10赋值给temp，返回next(g)

for i in g:
    print(i)
```

## 描述器

**描述器**（descriptor）：具有描述器协议方法`__set__`、`__get__`、`__delete__`三个中任意一个方法的python对象，其中只有`__get__`方法的对象被称为：**非数据描述器**(non-data desriptor)，其他的都称为：**数据描述器**(data descriptor)。

而这三种方法只有当类的实例出现在一个所有者类（owner class）之内时才有效，也就是说，描述器必须出现在所有者类或其父类的字典 `__dict__` 里。这里提到了两个类，一是定义了描述器协议的描述器类，另一个是使用描述器的所有者类。

描述器是一个有”绑定行为”的对象属性（object attribute），它的属性访问被描述器协议方法重写。

描述器往往以装饰器的方式被使用，导致二者常被混淆。描述器类和不带参数的装饰器类一样，都传入函数对象作为参数，并返回一个类实例，所不同的是，装饰器类返回`callable`的实例，描述器则返回描述器实例。

[Python描述器解析-简书](https://www.jianshu.com/p/58f1df955bda)

[Python描述器-知乎](https://zhuanlan.zhihu.com/p/32764345)

```python
class M:
    """资料装饰器"""
    def __init__(self):
        self.x = 1

    def __get__(self, instance, owner):
        return self.x

    def __set__(self, instance, value):
        self.x = f"haha-{value}"

class N:
    """非资料装饰器"""
    def __init__(self):
        self.x = 1

    def __get__(self, instance, owner):
        return self.x

class C:
    m = M()
    n = N()
    def __init__(self, m, n):
        self.m = m
        self.n = n

# c = C(2, 5)
```

描述器常在**所有者类或其实例**中被调用。对于实例对象，`object.__getattribute__()`会把`c.x`转化为`type(c).__dict__['x'].__get__(c, type(c))`；对于类，`type.__getattribute__()`把`C.x`转化为`C.__dict__['x'].__get__(None, C)`。

描述器被`__getattribute__()`方法调用，因而，重载 `__getattribute__()` 可能会妨碍描述器被自动调用。`__getattribute__()` 仅存在于继承自 object 的新式类之中，`object.__getattribute__()`和`type.__getattribute__()`对 `__get__()` 的调用不一样。

### 顺序

**实例属性查找顺序**

- 资料描述器总会覆盖实例字典，即资料描述器具有最高优先级；
- 非资料描述器可能会被实例字典覆盖，即非资料描述器具有最低优先级

### 应用

`property`是python最著名的描述器，非资料描述器常用于类的方法，如常见的`staticmethod`和`classmethod`，另外，Python 中的`function`，可以被认为是一个实现了`__get__()`的非资料描述器。

**property**

```python
class Property(object):
    def __init__(self, fget=None, fset=None, fdel=None, doc=None):
        self.fget = fget
        self.fset = fset
        self.fdel = fdel
        if doc is None and fget is not None:
            doc = fget.__doc__
        self.__doc__ = doc

    def __get__(self, obj, objtype=None):
        if obj is None:
            return self
        if self.fget is None:
            raise AttributeError("unreadable attribute")
        return self.fget(obj)

    def __set__(self, obj, value):
        if self.fset is None:
            raise AttributeError("can't set attribute")
        self.fset(obj, value)

    def __delete__(self, obj):
        if self.fdel is None:
            raise AttributeError("can't delete attribute")
        self.fdel(obj)

    def getter(self, fget):
        return type(self)(fget, self.fset, self.fdel, self.__doc__)

    def setter(self, fset):
        return type(self)(self.fget, fset, self.fdel, self.__doc__)

    def deleter(self, fdel):
        return type(self)(self.fget, self.fset, fdel, self.__doc__)
```

**classmethod**

```python
class ClassMethod(object):
    def __init__(self, f):
        self.f = f

    def __get__(self, obj, klass=None):
        if klass is None:
            klass = type(obj)
            
        def wrapper(*args):
            return self.f(klass, *args)
        return wrapper
```

**staticmethod**

```python
class StaticMethod(object):
    def __init__(self, f):
        self.f = f

    def __get__(self, obj, objtype=None):
        return self.f
```

**function**

```python
class Function(object):
    def __get__(self, obj, objtype=None):
        return types.MethodType(self, obj, objtype)
```

```python
##--------------------------------------------------------

class Meta(type):
    @classmethod
    def __prepare__(mcs, name, bases, **kwargs):
        print('  Meta.__prepare__(mcs=%s, name=%r, bases=%s, **%s)' % (
            mcs, name, bases, kwargs
        ))
        return {}
    def __new__(mcs, name, bases, attrs, **kwargs):
        print('  Meta.__new__(mcs=%s, name=%r, bases=%s, attrs=[%s], **%s)' % (
            mcs, name, bases, ', '.join(attrs), kwargs
        ))
        return super().__new__(mcs, name, bases, attrs)
    def __init__(cls, name, bases, attrs, **kwargs):
        print('  Meta.__init__(cls=%s, name=%r, bases=%s, attrs=[%s], **%s)' % (
            cls, name, bases, ', '.join(attrs), kwargs
        ))
        return super().__init__(name, bases, attrs)
    def __call__(cls, *args, **kwargs):
        print('  Meta.__call__(cls=%s, args=%s, kwargs=%s)' % (
            cls, args, kwargs
        ))
        return super().__call__(*args, **kwargs)

class Class(metaclass=Meta, extra=1):
    def __new__(cls, myarg):
        print('  Class.__new__(cls=%s, myarg=%s)' % (
            cls, myarg
        ))
        return super().__new__(cls)

    def __init__(self, myarg):
        print('  Class.__init__(self=%s, myarg=%s)' % (
            self, myarg
        ))
        self.myarg = myarg
        return super().__init__()

    def __str__(self):
        return "<instance of Class; myargs=%s>" % (
            getattr(self, 'myarg', 'MISSING'),
        )
```

### 创建

**实例的创建**

第一步调用元类的`__call__`方法，而`__call__`又调用类的`__new__`方法，并将`__new__`方法返回给元类`__call__`，同时调用类的`__init__`方法，然后元类返回实例。

过程如下（每一个泳道表示一个类的定义声明，实线表示函数调用，虚线表示返回值）：

**类的创建**

元类`__prepare__`返回一个命名空间对象（类似于字典），元类`__new__`方法返回的是类的对象，元-元类`__call__`返回元类`__new__`的返回值。（如果它返回的是元类的一个实例，它同样也会调用元类的`__init__`方法）
