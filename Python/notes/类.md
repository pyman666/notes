## 属性

## 访问属性

- 类不能访问实例属性；实例可以“借用”类属性，但仅仅是访问，修改啥的只能修改实例属性（相当于创建了一个实例属性）；

- `_attr`，受保护的属性，[类/子类/实例/模块内/`import xx`]都可以访问，`from xx import *`不能访问，但是如在\_\_all\_\_中指定，也能访问；

- `__attr`，私有属性，[类内部]可以访问，[子类/实例/模块内]不能，模块间**同 \_attr**（`import xx`可以访问等等）。类外部可以通过 `_类__属性`访问；

- 通常应该让非公共名称以单下划线开头；但是，如果代码会涉及到子类，并且有些内部属性应该在子类中隐藏起来，那么才考虑使用双下划线方案。

## 操作属性

- `getattr(object, name[, default])`获取对象属性值，如果不提供该参数，在没有对应属性时，将触发 AttributeError；

- `setattr(object, name, value)`用于设置属性

- `delattr(object, name)`用于删除属性

- `hasattr(object, name)`判断是否有某属性

## property

经典类property只能读取，不能set，描述器也没用。经典类：没继承object，新式类：继承object，py2.x默认不继承，py3.x默认继承。
```python
class Person:
    def __init__(self, first_name):
        self.set_first_name(first_name)

    def get_first_name(self):
        return self._first_name

    def set_first_name(self, value):
        if not isinstance(value, str):
            raise TypeError('Expected a string')
        self._first_name = value

    def del_first_name(self):
        raise AttributeError("Can't delete attribute")

    name = property(get_first_name, set_first_name, del_first_name)

class Age:
    def __init__(self, age):
        self.age = age  # age，不是_age（已经在调setter了）

    @property
    def age(self):
        return self._age

    @age.setter
    def age(self, v):
        if not isinstance(v, int):
            raise TypeError('Expected int')
        self._age = v  # _age，不是age，否则会死循环

    @age.deleter
    def age(self):
        raise AttributeError("Can't delete attribute")
```

# 继承

python类继承指继承父类属性**使用权**（id同），而非复制。子类里修改相当于新增。

## MRO

- python3往后都是新式类，其继承遵循MRO（方法解析顺序）原则。整个MRO列表的构造是通过一个C3线性化算法来实现的，其实际上就是合并所有父类的MRO列表并遵循如下三条准则：

- 子类会先于父类被检查

- 多个父类会根据它们在列表中的顺序被检查

- 如果对下一个类存在两个合法的选择，选择第一个父类

- python继承顺序大致可以分为如下三类，可利用`inspect`模块查看MRO顺序：

- 单继承：从下往上

- 无重叠多继承：单调原则，从左往右，左侧都没有再到右侧

- 有重叠多继承：父类都找完再找爷爷类

## super

`super()`函数返回MRO链条的下级节点，**并不一定是父类**。当使用 super函数时，python会在MRO列表上继续搜索下一个类。只要每个重定义的方法统一使用 super并只调用它一次，那么控制流最终会遍历完整个MRO列表，每个方法也只会被调用一次。
```python
def super(cls, inst):
    mro = inst.__class__.mro()
    return mro[mro.index(cls) + 1]

class D:
    def __init__(self):
        print("d")
class B(D):
    def __init__(self):
        super().__init__()  # <=>super(B, self).__init__()，这里的self为A的实例self
        print("b")
class C(D):
    def __init__(self):
        super().__init__()
        print("c")
class A(B, C):
    def __init__(self):
        super().__init__()  # <=>super(A, self).__init__()，即调用B的__init__，参数为A的实例self
        print("a")
>>> A()
```

# 内存管理

python内存管理机制：**引用计数器机制** + **垃圾回收机制**

## 垃圾回收

垃圾回收用于补充引用计数器中如容器对象里**循环引用**未被释放的对象，当新增对象减去消亡对象达到一定阈值时触发**分代回收**机制，gc模块`gc.collect()`。也可通过**弱引用**`weakref`解决；

## 引用计数

- python 的 = ： ~~**非赋值**~~， 实为**引用**（取别名）；

- 对象**引用计数**+1:

- 对象被创建

- 对象被引用

- 对象被作为参数传入函数

- 对象作为元素存储在容器

- 对象引用计数-1:

- 对象的别名被显式销毁（del）

- 对象的别名被赋予新对象

- 一个对象离开其作用域（如函数执行完毕）

- 对象所在容器被销毁，或被从容器剔除
```python
m = M()  # 别名为m的M对象，别名为m的M对象引用计数为1
m1 = M()  # 别名为m1的另一M对象，计数1（与别名m的M不是同一个，两个内存）
m2 = m  # 给别名为m的M对象另取一个别名，引用计数为2
```
