
## if

对于`if a`这种写法：

- 是`a`是布尔值，结果明显；

- 若`a`是`None`，判断为`False`；

- 若`a`是数值，0为`False`，其它情况为`True`；

- 若`a`是序列（列表、字典等），空值（长度为0）为`False`，否则为`True`；

- 若`a`是自定义类型，若自定义类型有`__bool__`（优先）或`__len__`方法，按照该方法判断，否则该类型恒为`True`；
```python
a = False

if a is True:  # 是否是True本身
    pass

if a == True:  # 不建议，因为==可被重载，含义同上
    pass

if a:  # 分几种情况
    pass

if bool(a):  # 含义同上
    pass
```
# try

`else`分支：没有错误且没有`return`，运行；

`finally`分支：不管是否报错有没有`return`，都运行；

`finally`只能处理python层面的问题，`sigterm`/`sigkill`/`segfault`等都能阻止`finally`的运行
```python
def foo(x):
    try:
        # print(1 / x)
        # return 1 / x
        # sys.exit(0)
        # os._exit(0)
    except:
        print("except")
    else:
        print("else")
    finally:
        print("finally")
```
# with

`with`语句嵌套：
```python
with open("a.jpg", "rb") as from_:
    with open("b.jpg", "wb") as to_:
        im = from_.read()
        to_.write(im)

with open("a.jpg", "rb") as from_, open("b.jpg", "wb") as to_:
    im = from_.read()
    to_.write(im)
```
