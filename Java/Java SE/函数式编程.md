## 函子

## map

一般约定，函子的标志就是容器具有`map`方法，该方法将容器里面的每一个值，映射到另一个容器。任何具有`map`方法的数据结构，都可以当作函子的实现。
```java
class Functor {
  constructor(val) {
    this.val = val;
  }

  map(f) {
    return new Functor(f(this.val));
  }
}

(new Functor(2)).map(function (two) {
  return two + 2;
});
// Functor(4)

(new Functor('flamethrowers')).map(function(s) {
  return s.toUpperCase();
});
// Functor('FLAMETHROWERS')

(new Functor('bombs')).map(_.concat(' away')).map(_.prop('length'));
// Functor(10)
```
上面的例子说明，函数式编程里面的运算，都是通过函子完成，即运算不直接针对值，而是针对这个值的容器——函子。函子本身具有对外接口（`map`方法），各种函数就是运算符，通过接口接入容器，引发容器里面的值的变形。

## of

函数式编程一般约定，函子有一个`of`方法，用来生成新的容器（类似于面向对象编程中的`new`命令）。
```java
Functor.of = function(val) {
  return new Functor(val);
};
```
# 函数接口

C语言支持函数指针，它可以把函数直接当变量来使用。但是，Java没有函数指针这样的语法。所以它通过函数接口，将函数包裹在接口中，当作变量来使用。

函数式接口（Functional Inteface）也是Java interface的一种，但还需要满足：

- 一个函数式接口**只有**一个抽象方法(single abstract method)；

- Object类中的public abstract method不会被视为单一的抽象方法；

- 函数式接口可以有默认方法和静态方法；

- 函数式接口可以用`@FunctionalInterface`注解进行修饰。

## FunctionalInterface

- 一个接口只要满足只有一个抽象方法的条件，即可以当成函数式接口使用，有没有`@FunctionalInterface`都无所谓（即该注解就是一个承诺，承诺该接口世世代代都只会存在这一个抽象方法）；

- 如果使用了此注解，再往接口中新增抽象方法，编译器就会报错（使用了这个注解的接口，可放心使用`Lambda`来实例化）；

- 没有用`@FunctionalInterface`注解修饰时，则代表别人没有承诺该接口未来不增加抽象方法，不建议用`Lambda`来实例化。

# Lambda

Lambda表达式是Java的一个语法糖，主要用来定义行内执行的方法类型接口。其底层是基于函数接口来实现的，通过函数式接口识别。

## 表达式

- 可选类型声明：不需要声明参数类型，编译器可以统一识别参数值；

- 可选的参数圆括号：一个参数无需定义圆括号，但多个参数需要定义圆括号；

- 可选的大括号：如果主体包含了一个语句，就不需要使用大括号；

- 可选的返回关键字：如果主体只有一个表达式返回值，则编译器会自动返回值，大括号需要指定表达式返回一个值。
```java
// 完整形态：有输入参数，有返回值，有代码块。
(int a, int b) -> {
 int c = a + b;
 return c;
}

// 不需要返回值时可以省略return语句
(int a, int b) -> {
    int c = a + b;
}

// 代码块只有一句时可以省略大括号，默认返回这一句代码的执行结果
(int a, int b) -> a + b;

// 形参的类型可以根据函数式接口里的方法声明自行推断
(a, b) -> a + b;

// 只有一个参数时可以省略形参的小括号
a -> a * a;
```
## 方法引用

方法引用是用来直接访问类或者实例的已经存在的方法或者构造方法，通过`::`关键字获取方法或者构造函数的引用。方法引用提供了一种引用而不执行方法的方式，它需要由兼容的函数式接口构成目标类型上下文。计算时，方法引用会创建函数式接口的一个实例。

常用的方法引用有：

- `TypeName::staticMethod` - 引用类的静态方法，接口或枚举；

- `objectRef::instanceMethod` - 引用实例方法；

- `ClassName::instanceMethod` - 从类中引用实例方法；

- `TypeName.super::instanceMethod` - 从对象的父类型引用实例方法；

- `ClassName::new` - 引用一个类的构造函数；

- `ArrayTypeName::new` - 对指定数组类型的构造函数的引用
```java
// Uses a lambda expression
BiFunction<Integer, Integer, Integer> func1 = (x, y) -> Integer.sum(x, y);

// Uses a method reference
BiFunction<Integer, Integer, Integer> func2 = Integer::sum;
```
## 作用域

- 访问权限与匿名对象的方式非常类似，只能够访问局部对应的外部区域的局部final变量，以及成员变量和静态变量；

- 在Lambda表达式中能访问但不能修改域外的局部非`final`变量，因为在Lambda表达式中，域外的局部非final变量会在编译的时候，会被隐式地当做final变量来处理；

- Lambda表达式内部无法访问接口默认（`default`）方法

## 匿名内部类

Lambda表达式与匿名类的异同集中体现在以下三点上：

- Lambda就是为了优化匿名内部类而生，要比匿名类简洁的多得多；

- Lambda仅适用于函数式接口，匿名类不受限；

- 匿名类中的`this`是“匿名类对象”本身；Lambda表达式中的`this`是指“调用Lambda表达式的对象”。
```java
// Stream类中map的使用方法示例：
Stream.of("fo", "bar", "hello").map(new Function<String, Integer>() {
  @Override
  public Integer apply(String s) {
    return s.length();
  }
});

// 用Lambda表达式简化后的写法：
Stream.of("fo", "bar", "hello").map(s -> s.length());
```
# Stream

引入Stream概念用于解决已有集合类库既有的弊端，Stream流其实是一个集合元素的函数模型，它并不是集合，也不是数据结构，其本身并不存储任何元素（或其地址值）。

在`Stream`类上的操作有两种：中间操作和终止操作，中间操作返回的仍然是`Stream`类对象，而终止操作返回的是确定的值结果。
```java
public class Demo {
  public static void main(String[] args) {
    Optional<Integer> result = Stream.of("f", "ba", "hello")  // of返回Stream对象
        .map(s -> s.length())  // map返回Stream对象
        .filter(l -> l <= 3)  // filter返回Stream<对象
        .max((o1, o2) -> o1-o2);  // max终止操作：返回Optional
    System.out.println(result.get());  // 输出2
  }
}
```
## 获取流

- 所有的`Collection`集合都可以通过`stream()`默认方法获取流;

- `Stream`接口的静态方法`of`可以获取数组对应的流
```java
// 根据Collection获取流
public static void main(String[] args) {
	List<String> list = new ArrayList<>();
	Stream<String> stream1 = list.stream();

	Set<String> set = new HashSet<>();
	Stream<String> stream2 = set.stream();
}

// 根据Map获取流
public static void main(String[] args) {
	Map<String, String> map = new HashMap<>();
	Stream<String> keyStream = map.keySet().stream();
	Stream<String> valueStream = map.values().stream();
    Stream<Map.Entry<String, String>> entryStream = map.entrySet().stream();
}

// 根据Arrays获取流
public static void main(String[] args) {
	String[] array = { "张无忌", "张翠山", "张三丰", "张一元" };
	Stream<String> stream = Stream.of(array);
}
```

# Optional

Optional 类是一个可以为null的容器对象，它可以保存类型T的值，或者仅仅保存null。Optional 提供很多有用的方法，这样我们就不用显式进行空值检测。可以更加优雅地处理Java语言中的NPE（空指针）异常，可以从一定程度上代替`if`判断。
```java
Optional opt = Optional.empty();  // 创建一个空的Optional对象
Optional opt = Optional.of("a");  //创建一个Optional对象, 传入空抛NPE异常
Optional opt = Optional.ofNullable("a");  // 传入空会调用empty方法创建一个空Optional对象

opt.isPresent();  // 值存在返回true，否则false
opt.ifPresent(u -> System.out.println(u));  // 值存在则操作，否则不操作
opt.get();  // 值存在返回值，否则抛出NoSuchElementException异常
opt.orElse("a");  // // 值为空则返回orElse设置的默认值
opt.orElseGet(() -> "a".toUpperCase());  // 值为空则内部可以是一个实现Supplier接口的匿名内部类调用提供返回结果
opt.orElseThrow(IllegalArgumentException::new);  // 值为空则抛出后面的异常
opt.filter(s -> !"".equals(s));  // 无值或不符合要求返回空Optional
opt.map(String::trim);  // 无值或映射为null返回空Optional，否则返回映射值的Optional
opt.flatMap(...);  // 对映射的返回值有要求，如果值存在，返回基于Optional包含的映射方法的值，否则返回一个空的Optional

// 实际应用, 如优化if
public void f(Integer type){
    if(type = null) {
        return 1;
    } else {
        return type;  // old
    }
	return Optional.ofNullable(type).orElse(1);  // new
}
```
# Collectors

用于构建Collector，常与`Stream.collect()`方法一起使用
```java
Collectors.toList();
Collectors.toSet();
Collectors.toMap(k -> k, k -> k+1);  // 有重复的值会报异常，添加第三个参数mergeFunction来解决冲突的问题
Collectors.toCollection(LinkedList::new);  // 自己指定类型

Collectors.collectingAndThen(Collectors.toList(), s -> {return new ArrayList<>(s);});  // 可对生成的集合再做一次操作
Collectors.joining("-", "prefix", "suffix");  // 连接stream中的元素，类似字符串拼接
Collectors.counting();  // 统计stream中元素的个数
Collectors.summarizingDouble/Long/Int();  // 为stream中的元素生成了统计信息，返回的结果是一个统计类
Collectors.averagingDouble/Long/Int();  // 对stream中的元素做平均
Collectors.summingDouble/Long/Int();  // 对stream中的元素做sum操作
Collectors.maxBy()/minBy();  // 根据提供的Comparator，返回stream中的最大或者最小值
Collectors.groupingBy(String::length, Collectors.toSet());  // 根据某些属性进行分组，并返回一个Map
Collectors.partitioningBy(s -> s.length() > 3);  // 分为key为true和false两类group
```
