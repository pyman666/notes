## 属性

## 递归
```java
public int factorial(int n) {
    if (n == 1) {
        return 1;
    } else {
        return factorial(n-1) * n;
    }
}
```
## 重载

- 同一个类中多个方法同名，但是**形参列表**不一致；

- 参数不同指参数 **类型**、**个数**、**顺序**，至少有一个不同，参数名无要求；

- 方法名必须相同，返回类型无要求

## main方法

- `main`方法是java虚拟机调用；

- java虚拟机需要调用main方法，所以必须是`public`；

- java虚拟机执行main方法不需要创建对象，所以必须是`static`；

- 该方法接受String类型的数组参数，该数组中保存执行java命令时传递给所运行的类的参数；

- main方法中可以直接调用所在类的静态成员（类变量、类方法），不能直接访问所在类的非静态成员，必须创建该类的一个实例对象之后才能访问。

# 构造器

- 构造器也叫构造方法，用于完成新对象的初始化（而非创建），没有返回值，方法名和类名相同，构造器的调用由系统完成；

- 如果没有定义构造器，系统自动生成一个默认无参构造器，如`Cat () {}`，但一旦定义了自己的构造器，默认构造器就被覆盖了不能再使用，除非再显式定义一下

## 对象创建流程

- 先加载Person类信息（`Person.class`，只会加载一次）；

- 在堆中分配空间（地址）；

- 默认初始化（int 0、 String null等）；（根据属性定义等）显式初始化；构造器初始化；

- 把对象在堆中的地址赋给p，p是对象名或对象的引用；

- 进行指定初始化，比如`p.name = "jack"`等

# 代码块

又名初始化块，属于类中的成员，类似于方法，将逻辑语句封装在方法体中，通过`{...}`包围起来。与方法不同的是没有方法名、返回、参数，只有方法体，而且不用通过对象或类显示调用，而是加载类或创建对象时隐式调用。

- 代码块可以有修饰符，修饰符**只能**是`static`；

- 使用static修饰的是静态代码块，不修饰的是普通代码块；

- 静态代码块随着类的加载而加载，并且只会执行**一次**。普通代码块每创建一个对象**都会**执行。如果只是使用类的静态成员，普通代码块**不会**执行；

- 静态代码块只能直接调用静态成员，普通代码块可以调用任意成员；

- **静态**代码块和属性初始化在类加载时就执行完毕，优先于构造器和普通代码块执行；

- 构造器的最前面隐含了`super()`和调用**普通**代码块。

## 类加载

类什么时候被加载（还有加载几次的问题）：

- 创建对象实例（`new`）时；

- 创建子类对象实例，父类也会被加载（父类先加载，子类后加载）；

- 使用类的静态成员时。

## 调用顺序

创建一个对象时，在**一个类**中的调用顺序：

- 调用静态代码块和静态属性初始化（静态代码块和静态属性初始化调用优先级一样，如果有多个静态代码块和多个静态属性初始化，则按他们定义的顺序调用）；

- 调用普通代码块和普通属性初始化（优先级一样，多个按照定义顺序）；

- 调用构造器；

创建一个子类（继承关系）对象时的调用顺序：

- 父类静态代码块和静态属性（优先级同，按定义顺序执行）；

- 子类静态代码块和静态属性（优先级同，按定义顺序执行）；

- 父类普通代码块和普通属性初始化（优先级同，按定义顺序执行）；

- 父类构造器；

- 子类普通代码块和普通属性初始化（优先级同，按定义顺序执行）；

- 子类构造器；
```java
class A {
    {
        // do sth;
    }

    public A() {
        // 隐藏 super();
        // 隐藏 调用普通代码块；
        // do sth;
    }
 }
```
# 访问权限

## 包

作用：区分相同名字的类，类多时管理类，控制访问范围

- `package`：需要放在类的最上面，一个类中最多只有一句`package`；

- `import`：放在`package`下面，类定义前面，可以多句，没有顺序要求

## 访问修饰符

java提供了4种访问控制修饰符，用于控制方法和属性的访问权限（范围）。

- `public`：对外公开；

- `protected`：对子类和同一个包中的类公开；

- `默认`：对同一个包的类公开；

- `private`：只有类本身可以访问，不对外公开

注意事项：

- 修饰符可以修饰：类、类中的属性、方法（**没有构造器**）；

- **只有**`public`和`默认`才能修饰类

|     |        |        |        |         |     |
| --- | ------ | ------ | ------ | ------- | --- |
|     | **同类** | **同包** | **子类** | **不同包** |     |
|     |        |        |        |         |     |

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **public** | √ | √ | √ | √ |
| **protected** | √ | √ | √ | × |
| **默认** | √ | √ | × | × |
| **private** | √ | × | × | × |
# 封装

**封装**指把抽象出的数据（属性）和对数据的操作（方法）封装在一起，数据被保护在内部，程序的其他部分只能通过被授权的操作（方法）才能对数据进行操作（想象成电视机）。

# 继承

**继承**可以解决代码复用的问题，子类会自动拥有父类定义的属性和方法，父类又叫超类、基类，子类又叫派生类。可以用`a instanceof B`查看a的**运行类型**是否是B类或者B的子类。
```java
class Son extends Father {}

Son son = new Son();
son instanceof Son;  // true
son instanceof Father;  // true

Father man = new Son();
man instanceof Father;  // true
man instanceof Son;  // true
```
- 子类继承了**所有的**属性和方法，但是私有属性和方法不能在子类直接访问，要通过公共方法访问；

- 子类**必须**调用父类的构造器，完成父类的初始化；

- 当创建子类对象时，不管使用子类哪个构造器，默认**总会**调用父类无参构造器，如父类没有提供无参构造器，则**必须**在子类构造器中用`super`指定使用父类的哪个构造器完成对父类的初始化；

- 如果希望指定调用父类的某个构造器，则显式地调用一下；

- `super`使用时需要放在构造器**第一行**；

- 由于`this`和`super`都要放在构造器第一行，因此这两个方法不能共存在一个构造器；

- 父类构造器的调用不限于直接父类，将一直往上追溯直到Object类；

- 子类最多只能直接继承一个父类，即java是单继承机制；

- 不能滥用继承，子类和父类之间必须满足 is-a 的逻辑关系。

## this

JVM会给每个对象分配`this`，代表**当前对象**。

- this可用来访问：本类的属性、方法、构造器；

- this访问属性（`this.name`）用于区分当前类的属性和局部变量；

- this访问方法（`this.foo(args)`）与直接调用方法有差异（需结合继承部分）；

- this访问构造器（`this(args)`）时只能在构造器中调用另外一个构造器，且必须放在**第一行**语句；

- this 不能在类定义的外部使用，只能在类定义的方法中使用
```java
class Dog {
    public Dog (String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```
## super

super代表**父类的引用**，可以访问：父类的属性、方法、构造器。

- 访问父类属性（`super.name`）但**不能**访问父类的private属性；

- 访问父类方法（`super.foo(args)`）但**不能**访问父类的private方法；

- 访问父类构造器（`super(args)`）只能放在构造器**第一行**，且只能出现**一句**。

- 当子类中和父类中的成员（属性、方法）重名时，访问父类成员**必须**用super；如果没有重名，用 super、this、直接访问 是**一样**的效果；

- super访问不限于直接父类，多个基类遵循就近原则；

|  |  |  |
| --- | --- | --- |
| **区别** | **this** | **super** |
| 访问属性 | 访问本类属性，本类没有就查父类 | 从父类开始查找属性 |
| 调用方法 | 调用本类方法，本类没有就调父类 | 从父类开始查找方法 |
| 调用构造器 | 调用本类构造器，须放在构造器首行 | 调用父类构造器，须放在子类构造器首行 |
| 特殊 | 表示当前对象 | 子类中访问父类对象 |
## 重写

又名方法覆盖，指子类有一个方法，和父类（不一定是直接父类）某个方法的名称、返回类型、参数都一样；属性没有重写之说，属性的值看**编译类型**。

- 子类方法的名称、参数，要和父类方法完全一样；

- 子类方法的返回类型要和父类方法返回类型一样，或是父类返回类型的子类；

- 子类方法**不能**缩小父类方法的访问权限。

# 多态

多态指方法或对象具有多种形态（应用例如：方法形参设为父类，实参为子类，统一方法定义）。

- 方法多态：重载、重写；

- **对象多态**：

- 一个对象的**编译类型**和**运行类型**可以不一致；

- 编译类型在定义对象时就确定了，不能改变；运行类型是可以变化的；

- 编译类型看定义时`=`的左边，运行类型看`=`的右边；

- 方法执行的时候看**运行类型**，属性的值看**编译类型**。

## 向上转型

父类的引用指向了子类对象

- 编译类型看左边，运行类型看右边；

- 可以调用父类中的所有成员（需遵循访问权限）；

- **不能调用**子类中的特有成员。
```java
Animal animal = new Dog(); // 向上
// animal.wangwang();  错误，没有wangwang
```
## 向下转型

- 只能强转父类的引用，不能强转父类的对象；

- 父类的引用**必须**指向的是当前目标类型的对象（先向上的才能再向下）；

- **可以**调用子类类型的所有成员。
```java
Animal animal = new Dog();  // 向上
Dog dog = (Dog) animal;  // 向下
// Cat cat = (Cat) animal;  错误，只能Dog
dog.wangwang();  // 正确
```
## 动态绑定 ★

- 当调用对象**方法**的时候，该方法会和该对象的内存地址（**运行类型**）绑定；

- 当调用对象属性的时候，没有动态绑定机制，哪里声明哪里使用
```java
class A {
    public int i = 10;

    public int getI() {return i;}
    public int sum1() {return getI() + 10;}
    public int sum2() {return i + 10;}
}

class AA extends A {
    public int i = 20;

    public int getI() {return i;}
}

A a = new AA();
a.sum1();  // 20 + 10
a.sum2();  // 10 + 10
```
## 多态数组

数组的定义类型为父类类型，里面保存的实际元素类型为子类类型。
```java
A[] arr = new A[2];

// arr[i] 编译类型是A，运行类型是根据实际情况由JVM来判断
arr[0] = new A();
arr[1] = new AA();

// 调用特有方法
for (int i = 0; i < arr.length; i++) {
    if (arr[i] instanceof AA) {
        ((AA) arr[i]).aa();
    }
}
```
## 多态参数

方法定义的形参类型为父类类型，实参类型允许为子类类型。
```java
public void foo(A arg) {
    if (arg instanceof AA) {
        ((AA) arg).aa();
    } else {
        arg.a();
    }
}
```
# 其他修饰符

## static

用`static`修饰的变量和方法叫类变量、类方法

### 类变量

类变量也叫静态变量、静态属性，用`static`修饰。

- 类变量是同一个类所有对象共享的变量，任何一个该类的对象去访问，取到的都是相同的值，修改的也是同一个变量；实例变量（普通属性）是每个对象独享的；

- 类变量随着类的加载而创建，没有创建对象实例也能访问（遵守访问权限）。
```java
class A {
    public static int n;  // 推荐
    static public int n;
}

A a = new A();
a.n;
A.n;  // 推荐，普通属性不行
```
### 类方法

类方法也叫静态方法，用`static`修饰。

- 当方法中不涉及任何和对象相关的成员，则可以将方法设计成类方法，提高开发效率（如**工具类**）；

- 类方法和普通方法都是随着类的加载而加载，将结构信息存储在方法区；

- 类方法中**不能**使用`this`和`super`，普通方法中可以；

- 类方法可以通过类名或者对象名来调用（须遵循访问权限，一般不需要创建对象），普通方法需要通过对象名调用，不能通过类名调用；

- 类方法**只能**访问类变量或者类方法，普通方法能访问普通方法也能访问类方法；

## final

`final`可以修饰类、属性、方法、局部变量（没有构造器）。

使用场景：

- 不希望类被**继承**时，可以用final修饰；

- 不希望父类某个方法被子类**重写**时，可以用final修饰；

- 不希望类的某个属性值被**修改**，可以用final修饰；

- 不希望某个局部变量被**修改**，可以用final修饰。

注意事项：

- final修饰的属性又叫**常量**，一般用 AA\_BB 来命名；

- final修饰的属性在定义时**必须**赋初值，并且以后**不能**修改。赋值的位置可以是：定义时、构造器中、代码块中；

- 如果final修饰的属性是静态的，则赋值的位置只能是：定义时、静态代码块，**不能**在构造器中赋值；

- final类**不能**继承，但能实例化对象；

- 如果类不是final类，但是含有final方法，则该方法虽然不能重写，但是可以被继承；

- 一般如果类已经是final类，就没必要将方法修饰成final方法；

- final不能修饰构造器；

- final和`static`往往搭配使用，效率更高，底层编译器做了优化；

- 包装类（Integer等）都是final类，String也是final类。

## abstract

当父类的某些方法需要声明，但是又不确定如何实现时（由子类实现），可以将其声明为抽象方法，那么该类就是抽象类。

- `abstract`只能修饰类和方法，不能修饰其他的；

- 所谓抽象方法就是没有实现（方法体）的方法；

- 抽象类**不能**被实例化；

- 当一个类中存在抽象方法时，需要将类声明为抽象类；

- 抽象类不一定要包含abstract方法，可以没有；

- 抽象类可以有任意成员（非抽象方法等）；

- 如果一个类继承了抽象类，则它**必须**实现抽象类的所有抽象方法，除非它自己也声明为抽象类；

- 抽象方法**不能**使用private、final、static来修饰，因为这些关键字都是和重写相违背的。
```java
abstract class Animal {
    public abstract void eat();
}
```
# 内部类

一个类内部又嵌套了另一个类结构，内部的类称为内部类。内部类最大的特点是可以**直接**访问私有属性，并且可以体现类与类之间的包含关系。

主要有四种内部类：

- 定义在外部类局部位置（如方法内）上（外部其他类不能访问）：

- 局部内部类（有类名）；

- 匿名内部类（没有类名）；

- 定义在外部类成员位置上（外部其他类也能访问）：

- 成员内部类（没用static修饰）；

- 静态内部类（使用static修饰）
```java
class Outer {  // 外部类
    class Inner {};  // 内部类
}

class Other {}  // 外部其他类
```
## 局部内部类

定义在外部类的局部位置上，如方法中，有类名。

- 可以直接访问外部类的所有成员，包括私有的；

- **不能**添加访问修饰符（public），因为其地位就是一个局部变量，局部变量不能使用修饰符。但是可以用final修饰，因为局部变量可以使用final；

- 作用域：仅仅在定义它的方法或者代码块中；

- 局部内部类访问外部类成员：直接访问；

- 外部类访问局部内部类成员：创建对象再访问（必须在作用域内）；

- 外部其他类不能访问局部内部类；

- 如果外部类和局部内部类的成员重名，默认遵循就近原则，如果想访问外部类的成员，可以使用`Outer.this.成员`的方式访问。
```java
class Outer {  // 外部类
    private int n = 100;

    public void foo () {
        final class Inner {  // 局部内部类
            public void f() {
                System.out.println(n);  // 直接访问外部类私有成员
            }
        }

        Inner inner = new Inner();
        inner.f();  // 外部类调用内部类方法
    }
}
```
## 匿名内部类 ★

定义在外部类的局部位置上，如方法中，没有类名，其同时还是一个对象。

可分为：基于接口的匿名内部类、基于类的匿名内部类，形如：`new A(...) {...}`。

- 各项注意点同上
```java
interface IA {
    public void cry();
}

class Boss {
    public Boss(String name) {}
    public void test() {}
}

class Outer {
    private int n = 100;

    public void foo(IA ia) {
        ia.cry();
    }

    public void foo() {
        // 基于接口的匿名内部类
        IA tiger = new IA() {  // 编译类型：IA，运行类型：匿名内部类
            public void cry() {
                System.out.println("老虎叫唤...");
            }
        }
        tiger.getClass();  // Outer$1
        tiger.cry();  // 匿名内部类使用一次就不能再使用了，tiger可以一直使用

        // 基于类的匿名内部类
        Boss boss0 = new Boss("eric");  // 编译类型：Boss，运行类型：Boss
        Boss boss1 = new Boss("jack") {  // 编译类型：Boss，运行类型：匿名内部类
            public void test() {
                System.out.println("匿名内部类重写test");
            }
        }
        boss1.getClass;  // Outer$2
    }

    // 最佳实践：当作实参直接传递
    public static void main(String[] args) {
        foo(new IA() {
            public void cry() {
                System.out.println("小喵叫唤...");
            }
        });
    }

}
```
## 成员内部类

定义在外部类的成员位置，没有static修饰。

- 可以直接访问外部类的所有成员，包括私有的；

- 可以添加任意访问修饰符，因为它的地位就是一个成员；

- 作用域：和外部类的其他成员一样；

- 成员内部类访问外部类成员：直接访问；

- 外部类访问成员内部类成员：创建对象再访问；

- 外部其他类**也能**访问成员内部类（遵守访问权限）；

- 如果外部类和成员内部类的成员重名，默认遵循就近原则，如果想访问外部类的成员，可以使用`Outer.this.成员`的方式访问。
```java
class Outer {
    private int n = 10;

    Class Inner {
        public void foo() {
            System.out.println(n);
        }
    }

    public void getInner() {
        return new Inner();
    }
}

Class Other {
    public static void main(String[] args) {
        Outer outer = new Outer();

        // 外部其他类调用成员内部类
        Outer.Inner inner = outer.getInner();
        Outer.Inner inner = outer.new Inner();  // 相当于把new Inner()当作outer的成员
        Outer.Inner inner = new Outer().new Inner();
    }
}
```
## 静态内部类

定义在外部类的成员位置，有static修饰。

- 可以直接访问外部类的所有成员，包括私有的，但**不能**直接访问非静态成员；

- 可以添加任意访问修饰符，因为它的地位就是一个成员；

- 作用域：和外部类的其他成员一样；

- 静态内部类访问外部类成员：直接访问；

- 外部类访问静态内部类成员：**创建对象**再访问；

- 外部其他类**也能**访问成员内部类（遵守访问权限），可以通过静态内部类类名直接访问（不需要new）；

- 如果外部类和匿名内部类的成员重名，默认遵循就近原则，如果想访问外部类的成员，可以使用`Outer.成员`（没有`this`）的方式访问。
```java
class Outer {
    private int n1 = 10;
    private static int n2 = 20;

    static Class Inner {
        public void foo() {
            System.out.println(n2);
        }
    }

    public void getInner() {
        return new Inner();
    }

    public static void getInner_() {
        return new Inner();
    }
}

class Other {
    public static void main(String[] args) {
        Outer outer = new Outer();

        // 外部其他类调用成员内部类
        Outer.Inner inner = outer.getInner();
        Outer.Inner inner = Outer.getInner();
        Outer.Inner inner = outer.Inner();
        Outer.Inner inner = new Outer.Inner();
    }
}
```
# 注解

注解（Annotation）也被称为**元数据**（Metadata），用于修饰 包、类、方法、属性、构造器、局部变量等

- 和注释一样，注解不影响程序逻辑，但注解可以被编译或运行，相当于嵌入在代码中的补充信息；

- 在JavaSE中，注解的使用目的比较简单，JavaEE中注解占据更重要的角色。

## 常用注解

- `@Override`：限定某个方法是重写父类方法，只能用于方法。如果没有构成重写，报错；

- `@Deprecated`：某个成员（类、方法等）已过时；

- `@SuppressWarning`：抑制编译器警告

## 元注解

修饰注解的注解

- `@Retention`：指定注解保留的范围（三种：SOURCE、默认CLASS、RUNTIME）；

- `@Target`：指定注解可以在哪些地方使用；

- `@Documented`：该注解在javadoc体现；

- `@Inherited`：子类会继承父类注解。
```java
@Target({ElementType.TYPE})
@Retention(RetentionPolicy.RUNTIME)
public @interface MyAnnotation {
	public boolean isFull() default false;
}
```
# 接口

接口就是给出一些没有实现的方法封装到一起，等某个类要用的时候，再根据实际情况把这些类写出来。

接口是java对单继承机制的补充，**单继承多接口**，继承是 is-a，接口是 like-a。

- 接口不可以被实例化；

- 接口可以有抽象方法、静态方法、默认方法，默认方法需用`default`关键字修饰；

- 接口中所有的方法都是`public`，可以省略（不是`默认`）；

- 接口中的抽象方法可以省略`abstract`关键字；

- 普通类实现接口，**必须**实现所有方法；抽象类实现接口**可以**不用实现接口方法；

- 接口中的属性**只能**是final的，实际相当于`public static final 属性;`，通过`接口名.属性名`访问；

- 一个类可以实现**多个**接口（`class A implements B, C {}`）；

- 一个接口不能继承其他类，但是能继承**多个**别的接口（`interface A extends B, C {}`）；

- 接口的修饰符只能是`public`、`默认`，跟类一样。
```java
interface A extends B, C {
    // 属性;  等价于 public static final 属性;
    // 抽象方法;  等价于 public abstract 抽象方法;
    // 默认方法;
    // 静态方法;
}

class AA implements A, B, C {
    // 自己的属性；
    // 自己的方法；
    // 必须实现接口的方法；
}
```
## 多态

接口类型的变量，可以指向实现了该接口的类的对象实例。

接口存在多态传递现象：如果IG继承了IH接口，A类实现了IG接口，就相当于A也实现了IH（A也要实现IH的方法）。

- 多态参数：形参是接口类型，就可以接收实现了接口的类的对象实例；

- 多态数组：接口类型的数组，就可以存放实现了接口的类的对象实例
```java
interface IF {}
class A implements IF {}
class B implements IF {}

IF a  = new A();
a = new B();

class A {}
class AA extends A {}
class AB extends A {}

A a = new AA();
a = new AB();
```
```java
interface IH {}
interface IG extends IH {}
class A implements IG {}

IG ig = new A();
IH ih = new A();
```
