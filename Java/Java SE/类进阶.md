## 类加载

静态加载：编译时加载相关的类，如果没有则报错，依赖性太强；

动态加载：运行时加载需要的类，如果运行不用该类不报错，降低了依赖性
```java
// 静态
Dog dog = new Dog();
//动态
Class cls = Class.forName("Dog");
Object dog = cls.newInstance();
```
类加载时机：

- 创建（`new`）对象时（静态加载）；

- 子类被加载时，父类也加载（静态加载）；

- 调用类中的静态成员时（静态加载）；

- 通过反射（动态加载）

## 结构信息

### Class

Class也是类，继承Object。

- Class类对象不是`new`出来的，而是系统创建的；

- 对于某个类的Class对象，内存中只有一份，因此类只加载一次；

- 每个类的实例都会记得自己是由哪个Class实例所生成；

- 通过Class可以完整地得到一个类的完整结构；

- Class对象存放在堆中；

- 类的字节码二进制数据放在方法区，亦可称为类的元数据（成员、访问权限等）

获取方式：
```java
// 法一，多用于配置文件
Class cls = Class.forName("com.eric.Cat");

// 法二，多用于参数传递，最为安全可靠，性能最高
Class cls = Cat.class;

// 法三
Class cls = cat.getClass();

// 法四，类加载器
ClassLoader loader = car.getClass().getClassLoader();
Class cls = loader.loadClass("com.eric.Cat");

// 基本数据类型
Class cls = int.class;

// 包装类
Class cls = Integer.TYPE;
```
常用方法：
```java
Class cls = Class.forName("com.eric.Cat");  // Cat的Class对象
Cat cat = (Cat)cls.newInstance();  // Cat的实例

Class a = cls.getClass();  // cls的运行类型，java.lang.Class
String a = cls.getName();  // Cat的全类名
String a = cls.geSimpletName();  // Cat的简单类名
Package a = cls.getPackage();  // Cat的包
Class a = cls.getSuperClass();  // Cat父类的Class对象
Class[] a = cls.getInterfaces();  // Cat的接口
ClassLoader a = cls.getClassLoader();  // Cat的类加载器
Annotation[] a = cls.getAnnotations();  // Cat的注解信息

Field a = cls.getField("color");
Field[] a = cls.getDeclaredField("color");
Field[] a = cls.getFields();  // 本类和父类所有public属性
Field[] a = cls.getDeclaredFields();  // 本类所有属性，包含非public
Method a = cls.getMethod("miao");
Method a = cls.getDeclaredMethod("miao", String.class);
Method[] a = cls.getMethods();  // 本类和父类所有public方法，
Method[] a = cls.getDeclaredMethods();
Constructor a = cls.getConstructor(String.class);
Constructor a = cls.getDeclaredConstructor(String.class);
Constructor[] a = cls.getConstructors();  // 本类所有public构造器
Constructor[] a = cls.getDeclaredConstructors();
```
### Field
```java
Class cls = Class.forName("com.eric.Cat");
Cat cat = (Cat)cls.newInstance();

Field f = cls.getDeclaredField("color");
f.setAccessible("true");  // 爆破
f.get(cat);  // 传统：对象.属性，反射：属性.get(对象)
f.set(cat, "橘猫");  // 静态属性，set/get中的cat可以写成null

String a = f.getName();  // 属性名
Class a = f.getType();  // 属性类型
int a = f.getModifiers();  // 属性修饰符，默认-0，pulic-1，private-2，protected-4，static-8，final-16，多个修饰符值相加
```
### Method
```java
Class cls = Class.forName("com.eric.Cat");
Cat cat = (Cat)cls.newInstance();

Method m = cls.getDeclaredMethod("miao");
m.setAccessible(true);  // 爆破
m.invoke(cat);  // 传统：对象.方法()，反射：方法.invoke(对象)，静态方法cat可以写成null
Method m = cls.getDeclaredMethod("miao", String.class);
Object v = m.invoke(null, "miaomiao");  // 统一用Object接收
v.getClass();  // String，因为运行类型是String

String a = m.getName();  // 方法名
Class a = m.RetrunType();  // 方法类型
Class[] a = m.getPOarameterTypes();  // 方法参数类型数组
int a = m.getModifiers();  // 方法修饰符
```
### Constructor
```java
Class cls = Class.forName("com.eric.Cat");
Cat cat = (Cat)cls.newInstance();  // 无参构造器，已过时

Constructor c = cls.getDeclaredConstructor(String.class);  // 私有构造器
c.setAccessible(true);  // 爆破以访问非public
Cat tom = (Cat)c.newInstance("Tom");

String a = m.getName();  // 构造器名（全类名）
Class[] a = m.getPOarameterTypes();  // 构造器参数类型数组
int a = m.getModifiers();  // 构造器修饰符
```
