## 基本类

## Object

java所有类都是Object类的子类。

`equals`

- `==`是比较运算符，如果判断基本类型，判断**值**是否相等；如果判断引用类型，判断**地址**是否相等（是不是同一个对象）；

- `equals()`是Object类中的方法，**只能**判断引用类型，默认判断地址是否相等，子类中往往会重写

`hashCode`

- 提高具有哈希结构的容器的效率；

- 不能完全将哈希值等价于地址；

- 两个引用指向同一个对象，哈希值一样，不同的对象，哈希值不一样。

`toString`

默认返回：`全类名（包名+类名）+ @ + 十六进制哈希值`，子类往往重写。

- 当直接输出一个对象时，toString默认会被调用；

- 重写toString方法，打印对象或者拼接对象时，都会自动调用该对象的toString形式。

`finalize`

当对象被回收时，系统自动调用该对象的`finalize`方法，子类可以重写改方法。

- 什么时候被回收：当某个对象没有任何引用时，则JVM就认为这个对象是一个垃圾对象，就会使用垃圾回收机制来销毁对象，在销毁该对象前，先调用finalize方法；

- 垃圾回收机制的调用，是由系统来决定的，也可以通过`System.gc()`主动出发垃圾回收机制。

# 枚举类

枚举是一种特殊类，里面只包含一组有限的特定的对象。

## 自定义枚举类
```java
class Season {
    private String name;

    public static final Season SPRING = new Season("春天");
    public static final Season SUMMER = new Season("夏天");
    public static final Season AUTUMN = new Season("秋天");
    public static final Season WINTER = new Season("冬天");

	private Season(String name) {
        this.name = name;
    }

    public String getName() {
        return name;
    }
}
```
## enum

`enum`关键字：

- 使用enum关键字开发一个枚举类（也是类）；

- 枚举类默认隐式继承`Enum`类，所以不能继承其他类；

- 枚举类也能实现接口；

- 多个枚举对象使用`,`间隔，最后一个`;`结尾，且枚举对象必须放在**行首**；

- `public static final Season SPRING = new Season("春天");`被简化成`SPRING("春天"),`；

- 必须知道调用的哪个构造器，如果使用无参构造器创建枚举对象，实参列表和小括号都可以省略；

`Enum`类：

- `name()`：枚举对象的名称（`BOY`）；

- `toString()`：同`name()`（`BOY`）；

- `ordinal()`：该枚举对象的次序，从0开始（`0`）；

- `values()`：所有的枚举对象数组（`Gender.values() [BOY, GIRL]`）；

- `valueOf()`：将字符串转成枚举对象，要求字符串必须为已有的常量名，否则报错（`Gender.valueOf("BOY")`）；

- `compareTo()`：比较两个枚举常量的位置号（`Gender.BOY.compareTo(Gender.GIRL) 0-1=-1`）。
```java
enum Gender {
    BOY, GIRL;
}

Gender boy = Gender.BOY;
System.out.println(boy);  // BOY

enum Season {
    SPRING("春天"),
    SUMMER("夏天"),
    AUTUMN("秋天"),
    WINTER("冬天");

    private String name;

	private Season(String name) {
        this.name = name;
    }

    public String getName() {
        return name;
    }
}
```
# 字符串

## String

String对象用于保存字符串，也就是一组字符序列。字符串的字符使用Unicode字符编码，一个字符（不区分字母还是汉字）占两个字节。

- 实现了`Serializable`接口，说明String可以串行化（可以在网络传输）；

- 实现了`Comparable`接口，说明可以比较大小；

- String是`final`类，不能被其他类继承，且字符串对象一旦被分配，其内容不可变；

- String有属性`private final char value[]`，用于存放字符串内容。因为是final，所以不可修改（非字符不可修改，而是**地址**不可修改。即`value`不能指向新的地址，但是单个字符内容是可以变化的）
```java
// 法一，直接赋值
String s = "eric";
// 法二，调用构造器
String s = new String("eric");
```
- 法一：先从常量池查看是否有"eric"数据空间，如果有，直接指向；如果没有，则重新创建，然后指向。s最终指向的是**常量池**的空间地址；

- 法二：先在堆中创建空间，里面维护了`value`属性，指向常量池的"eric"空间。如果常量池没有"eric"，重新创建。如果有，直接通过`value`指向。最终指向的是**堆**中的空间。
```java
String a = "eric";
String b = new String("eric");
a.equals(b);  // true
a == b;  // false
a == b.intern();  // true
b == b.intern();  //false
```
常用方法：
```java
String s = "eric";

s.length();  // 4
s.equals("Eric");  // false
s.equalsIgnoreCase("Eric");  // true
s.compareTo("kris");  // -6 前大正，后大负，等0

s.indexOf('a');  // -1 第一次出现的索引
s.indexOf("er");  // 0
s.lastIndexOf('a');  // -1 最后一次出现
s.charAt(0);  // 'e'
s.subString(2);  // "ic"
s.subString(0, 2);  // "er"

s.toUpperCase();  // "ERIC"
s.toLowerCase();  // "eric"
s.toCharArray();  // {'e', 'r', 'i', 'c'}
s.concat("sson");  // "ericsson"
s.replace("e", "E");  // "Eric" 替换所有的，s本身不变
s.split("r");  // {"e", "ic"}

String.format("eric%s", "sson");  // "ericsson"
```
- `intern`：调用时如果常量池已经包含一个内容相等的字符串，则返回池中的字符串。否则，将此String对象添加到池中，并返回此String对象的引用（返回的是常量池的地址）；

## StringBuffer

StringBuffer代表**可变**的字符序列，可以对字符串的内容进行增删。

- StringBuffer是一个容器，可变长度，可串行化，很多方法与String相同；

- 直接父类AbstractStringBuffer也有属性`char[] value`，但不是final，该`value`数组存放字符串内容，因此存放在堆中；

- StringBuffer是`final`类，不能被其他类继承
```java
String s = "eric";
// 法一
StringBuffer b = new StringBuffer(s);
// 法二
StringBuffer b = new StringBuffer();
b.append(s);

StringBuffer b = new StringBuffer("eric");
// 法一
String s = b.toString();
// 法二
String s = new String(b);
```
常用方法：
```java
StringBuffer b = new StringBuffer("eric");

b.length();  // 4
b.append("sson);  // ericsson
b.delete(1, 2);  // eic
b.replace(1, 2, "haha");  // ehahaic
b.insert(3, "y");  // eriyc
b.indexOf("z");  // -1
```
## StringBuilder

StringBuilder是一个可变的字符序列，提供了与StringBuffer兼容的API，但不保证同步（不线程安全）。

- StringBuilder可以作为StringBuffer的一个简易替换，用在字符串缓冲区被单个线程使用的时候。如果可能，建议优先采用StringBuilder，因为大多数时候比StringBuffer快；

- StringBuilder上主要操作是`append`和`insert`方法，可以重载这些方法以接受任意类型的数据

## 总结

String类是保存字符串常量的，每次更新都要重新开辟空间，效率较低（。所以提供了StringBuilder和StringBuffer来增强String的功能，提高效率。

- 字符串存在大量修改，单线程，StringBuilder；

- 字符串存在大量修改，多线程，StringBuffer；

- 字符串很少修改，被多个对象引用，String（如配置信息等）

# 数组

数组Arrays：

- 数组可以存放多个**同一类型**的数据。属于引用类型。

- 数组创建后没赋值，有默认值，整型`0`，浮点数`0.0`，`char` `\u0000`，`boolean` `false`，`String` `null`。

- 基本类型赋值，值就是具体数据，互不影响；数组默认为引用传递，赋的值是**地址**
```java
// 静态初始化
double[] a = {3, 5, 3.4, 2};
double a[] = {3, 5, 3.4, 2};

// 动态初始化
int[] a = new int[2];
for (int i = 0; i < a.length; i++) {
    a[i] = i;
}

// 二维数组
int[][] arr = {{1, 2, 3}, {1}};
int[] arr[] = {{1, 2, 3}, {1}};
int arr[][] = {{1, 2, 3}, {1}};

int[][] arr;
arr = new int[2][];
for (int i = 0; i < arr.length; i++) {
    for (int j = 0; j < arr[i].length; j++) {
        System.out.println(arr[i][j]);
    }
}
```
## Arrays

Arrays包含了一系列静态方法，用于管理或操作数组（排序、搜索等）。
```java
Integer arr[] = {1, -1, 0};

Arrays.toString(arr);  // [1, -1, 0]
List<Integer> list = Arrays.asList(1, 2, 3);  // 运行类型ArrayList
boolean eq = Arrays.equals(arr1, arr2);

Integer[] arr1 = Arrays.copyOf(arr, 4);  // [1, -1, 0, null] 底层调用arraycopy
Arrays.fill(arr, 99);  // [99, 99, 99]

int ind = Arrays.binarySearch(arr, 3);  // 二分法查找，要求排好序
Arrays.sort(arr);  // 排序，默认从小到大，会影响arr
Arrays.sort(arr, new Comparator<Integer> {
    @Override
    public int compare(Integer a, Integer b) {
        return b - a;  // 从大到小
    }
});
```
# 集合

数组局限：

- 数组长度开始时必须指定，而且一旦指定不能更改；

- 数组保存的必须为同一类型的元素；

- 数组增删元素等操作比较麻烦

集合优势：

- 集合可以动态保存任意多个对象，使用比较方便；

- 集合提供了一系列方便的操作对象的方法（add、remove、set、get等）；

- 集合增删元素等操作更方便

集合框架：

从上图可以看到，集合框架主要包括两种类型的容器：一种是集合（Collection，单列集合），存储一个元素集合，另一种是图（Map，双列集合），存储键/值对映射。Collection

接口又有 3 种子类型：List、Set、Queue，再下面是一些抽象类，最后是具体实现类。

## Collection

Collection接口没有直接的实现子类，是通过其子接口List和Set来实现的。

常用方法（以实现子类ArrayList为例）：
```java
Collection c = new ArrayList();
Collection c1 = new ArrayList();

int n = c.size();
boolean b = c.isEmpty();
boolean b = c.contains(18);
boolean b = c.containsAll(c1);

c.add("eric");
c.add(10);
c.addAll(c1);
c.remove("eric");
c.remove(0);  // 删除第一个
c.removeAll(c1);
c.clear();  // 清空
```
### 迭代器

Iterator对象称为迭代器，用于遍历集合中的元素。实现了Collection接口的集合类都有一个iterator()方法，用以返回一个迭代器。

Iterator仅用于遍历集合，本身不存放对象。
```java
Collection c = new ArrayList();

// 迭代器
Iterator it = c.iterator();
while (it.hasNext()) {
    return it.next();
}

// 增强for，底层也是迭代器
for（Object o : c）{
    return o;
}
```
### List

List接口是Collection接口的子接口

- List集合类中元素可重复、有序（添加顺序和取出顺序一致）；

- List集合中的每个元素都有其对应的顺序索引，即支持索引；

- List容器中的元素都对应一个整数型的序号，记载其在容器中的位置，可以根据序号存取容器中的元素；

- List接口常用实现类：ArrayList、LinkedList、Vector
```java
List s = new ArrayList();

s.add("eric");
s.add(0, "kris");  // 指定位置插入
s.addAll(s);
s.addAll(0, s);
s.get(0);  // 索引从0开始
s.indexOf("eric");
s.lastIndexOf("eric");  // 最后一次出现位置
s.remove("eric");
s.remove(0);  // 根据索引删除
s.set(0, "eric");  // 替换，索引一定要存在
s.subList(0, 2);  // [0, 2)
```
ArrayList

- ArrayList可以加入（多个）`null`；

- ArrayList是由数组来实现数据存储的；

- ArrayList基本等同于Vector，除了ArrayList线程不安全，但执行效率高。多线程情况下不建议使用ArrayList

Vector

- Vector底层也是一个对象数组`protected Object[] elementData`；

- Vector是线性同步的，即线程安全，需要考虑线程同步安全时考虑使用Vector

LinkedList

- LinkedList实现了双向链表和双端队列特点；

- 可以添加任意元素，可以重复，包括`null`；

- 线程不安全

### Set

Set接口是Collection接口的子接口

- 无序（添加和取出顺序不一致），没有索引（不能用索引for遍历）；

- 不允许重复元素，最多一个`null`；

- 常用实现子类：HashSet、TreeSet

HashSet

- HashSet实现了Set接口，不保证元素有序，取决于hash后

- HashSet底层是HashMap
```java
HashSet s = new HashSet();

s.add("eric");  // true
s.add("eric");  // false
s.add(new Dog("Tom"));  // true
s.add(new Dog("Tom"));  // true
s.add(new String("hsp"));  // true
s.add(new String("hsp"));  // false

s.remove("eric");
```
LinkedHashSet

- LinkedHashSet是HashSet的子类，不允许添加重复元素

- LinkedHashSet底层是LinkedHashMap；

- 遍历LinkedHashSet能确保插入顺序和遍历顺序一致

TreeSet

- 可排序

## Map

Map与Collection并列存在，用于保存具有映射关系的数据。

- Map中的key和value可以是任何引用类型的数据，会封装到HashMap$Node对象中；

- key不允许重复（原因和HashSet一样），value可以重复；

- key和value都可以为`null`，常用String类作为key；

- key和value之间存在单向一对一关系，即通过指定的key总能找到对应的value；

- Map一对k-v存放在一个Node中，又因为Node实现了Entry接口，故有时也称一对k-v就是一个Entity
```java
Map m = new HashMap();

m.size();
m.isEmpty();
m.put("eric", 18);
m.put(null, null);
m.putAll(m);
m.remove("kris");
m.clear();
Object o = m.get("eric");
boolean b = m.containsKey("eric");
boolean b = m.containsValue(18);
```
遍历：
```java
Map m = new HashMap();

// 法一
Set keySet = m.keySet();  // 获取所有键

for (Object k: keySet) {
    return m.get(k);
}

Iterator it = keySet.iterator();
while (it.hasNext()) {
    Object k = it.next();
    return m.get(k);
}

// 法二
Collection values = m.values();  // 获取所有值

for (Object v: values) {
    return v;
}

Iterator it = values.iterator();
while (it.hasNext()) {
    Object v = it.next();
    return v;
}

// 法三
Set entrySet = m.entrySet();  // 获取所有关系k-v

for (Object entry: entrySet) {
    Map.Enrty e = (Map.Entry) entry;
    return m.getKey() + m.getValue();
}

Iterator it = entrySet.iterator();
while (it.hasNext()) {
    HashMap$Node entry = it.next();
    Map.Enrty e = (Map.Entry) entry;
    return m.getKey() + m.getValue();
}
```
### HashMap

HashMap是Map接口使用频率最高的实现类

注意事项：

- key不能重复，值可以，添加相同的key，则会覆盖原来的k-v，等同于修改（key不替换，value替换）；

- 与HashSet一样，不保证映射的顺序，因为底层是以hash表的方式存储的；

- HashMap没有实现同步，线程不安全；

- HashMap（JDK8）底层是数组+链表+红黑树，k-v是一个Node，实现了Map.Entry

LinkedHashMap

- 键插入顺序和取出顺序相同

### HashTable

典型应用：Properties。Properties是HashTable的子类，使用类似于HashTable

注意事项：

## IO流

IO是Input/Output的缩写，用于处理数据传输，如读写文件、网络通讯等。Java程序中，对于数据的输入输出操作是以“流（Stream）”的方式进行的，java.io包下提供了各种“流”的类和接口。

按照操作数据单位不同：字节流（8bit，二进制文件）、字符流（按字符，文本文件）

### 字节流

InputStream抽象类是所有类字节输入流的超类，常用子类：

- FileInputStream：文件输入流

- BufferedInputStream：缓冲字节输入流

- ObjectInputStream：对象字节输入流

FileInputStream
```java

    System.out.println( (char)data );  // 中文会乱码

stream.close();  // 关闭流，释放资源

byte[] buf = new byte[8];  // 最多一次读8个字节
int data;
while ( (dataLen = stream.read(buf)) != -1 ) {  // 返回实际字节数
    System.out.println( new String(buf, 0, readLen) );  // 数据在buf中
}
stream.close();  // 关闭流，释放资源
```
FileOutputStream，如果文件不存在，会创建文件（前提是目录已存在）

文件拷贝
```java
String srcPath = "D://test.txt";
```

## 处理流

### 节点流vs处理流

**节点流**：可以从一个特定的数据源读写数据，是底层流/低级流，直接跟数据源相接。如FileReader、FileWriter等；

**处理流**：也叫包装流，包装节点流，既可以消除不同节点流的实现差异，也可以提供更方便的方法完成输入输出。，如BufferedReader、BufferedWriter等

处理流对节点流进行包装，使用了**修饰器**设计模式，不会直接与数据源相连。主要功能体现在：

- 性能提高：主要以增加缓冲的方式来提高输入输出的效率；

- 操作便捷：处理流提供了一系列方法来一次输入输出大批量数据

### 字符流

BufferedReader、BufferedWriter属于**字符流**，是按照字符来读写数据的，不要去操作二进制文件，否则可能造成文件损坏。

关闭时只需关闭外层流（处理流）即可。
```java
String path = "D:/test.txt";
BufferedReader br = new BufferedReader(new FileReader(path));
String line;
while ( (line + br.readLine()) != null ){  // 按行读取（不读换行）
	System.out.println(line);
}
br.close();  // 只需关闭处理流，底层自动关闭节点流
```
```java
String path = "D:/test.txt";
BufferedWriter bw = new BufferedWriter(new FileWriter(path, true));  // 追加
bw.write("hello world");
bw.newLine();  // 插入（跟系统相关的）换行
bw.close();
```
```java
BufferedReader br = new BufferedReader(new FileReader("a.py"));
BufferedWriter bw = new BufferedWriter(new FileWriter("b.py"));
String line;
while ( (line = br.readLine()) != null ) {
    bw.write(line);
    bw.newLine();
}
br.close();
bw.close();
```

### 对象流 ★

对象流用于对象的序列化和反序列化。ObjectInputStream反序列化、ObjectOutputStream序列化

序列化和反序列化：

- 序列化就是在保存数据时，保存数据的值和**类型**；

- 反序列化就是在恢复数据时，恢复数据的值和**类型**；

- 需要让某个对象支持序列化机制，必须让其类是可序列化的，该类必须实现如下两个接口之一：`Serizlizable`（推荐，标记接口没有方法）、`Externalizable`（需实现方法）

注意事项：

- 读写顺序要一致；

- 序列化的类中建议添加`seriaVersionUID`，为了提高版本兼容性；

- 序列化对象时，默认将里面所有的属性都进行序列化，除了`static`或`transient`修饰的成员；

- 序列化对象时，要求里面属性的类型也要实现序列化接口；

- 序列化具备可继承性，也就是如果某类已经实现了序列化，则其所有子类也已经默认实现了序列化
```java
class Dog implements Serizlizable {  // 实现Serizlizable
    private String name;
    private int age;
    private transient String color;
    private static final long seriaVersionUID = 1L;  // 序列版本号

    public Dog(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```
```java
String path = "D:/data.dat";  // 后缀随意，文件格式不是普通文本
ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream(path));

oos.writeInt(100);  // int->Integer 实现了Serizlizable
oos.writeBoolean(true);
oos.writeChar('a');
oos.writeDouble(9.5);
oos.writeUTF("hello world");  // String实现了Serizlizable
oos.writeObject(new Dog("旺财", 3));  // Dog实现了Serizlizable

oos.close();
```
读取（反序列化）的顺序要和保存（序列化）的顺序一致
```java
String path = "D:/data.dat";  // 后缀随意，文件格式不是普通文本
ObjectInputStream ois = new ObjectInputStream(new FileInputStream(path));

int a = ois.readInt();
boolean b = ois.readBoolean();
char c = ois.readChar();
double d = ois.readDouble();
String e = ois.readUTF();
Object o = ois.readObject();  // 底层 Object->Dog

ois.close();
```
