## 基本数据类型

## 条件控制

### if
```java
// 单分支
if (cond) {
    // do sth;
}

// 双分支
if (cond) {
    // do sth;
} else {
    // do sth;
}

// 多分支
if (cond1) {
    // do sth;
} else if (cond2) {
    // do sth;
} else {
    // do sth;
};
```
### switch
```java
switch (n) {
    case n1:
        // do sth;
        break;
    case n2:
        // do sth;
        break;
    default:
        // do sth;
        break;
}
```
- `n`**只能**是byte、short、int、char、enum、String；

- `case`中的值**只能**是常量不能是变量；

- 如果没有`break`，会顺序执行到switch结尾

## 循环控制

### for
```java
// 基本用法
for (int i = 1; i < 10; i++) {
    // do sth;
}

// 外部要使用 i 时
int i = 1;
for ( ; i < 10; ) {
    // do sth;
    i++;
}

// 增强for
int[] arr = {1, 2, 3};
for (int i : arr) {
    // do sth;
}
```
### while
```java
int i = 1;
while (i < 10) {
    // do sth;
    i++;
}
```
### dowhile

至少会执行一次
```java
int i = 1;
do {
    // do sth;
    i++;
} while (cond);
```
## 跳转控制

### break

- 可以使用标签指定推出哪层；

- 如果没有指定标签，默认退出**最近**的循环体

### continue

跳出本次循环

### return

跳出方法，如果在`main`中，表示退出程序

## 异常控制

程序执行中发生的不正常情况称为异常（语法错误和逻辑错误不是异常），可分为运行时异常和编译时异常。

### 常见异常

- `NullPointerException`：空指针异常，在需要对象的地方却使用`null`；

- `ArithmeticException`：数学运算异常，如除以0；

- `ArrayIndexOutOfBoundsException`：数组下标越界异常，下标为负或者大于等于数组长度；

- `ClassCastException`：类型转换异常，将对象强转为不是实例的子类时；

- `NumberFormatException`：数字格式不正确异常，当试图将字符串转为一种数值类型但实际格式不对时。

### 自定义异常

定义类继承`Exception`或`RuntimeException`：

- 继承`Exception`，属于编译异常；

- 继承`RuntimeException`，属于运行异常（一般继承`RuntimeException`，可以使用默认处理机制）
```java
class MyException extends RuntimeException {
    public MyException (String msg) {
        super(msg);
    }
}
```
### try

程序员在代码中捕获异常，自行处理。
```java
try {
    // do sth;
} catch (Exception e) {  // 可以省略，适用于不管是否异常，都必须执行某个业务逻辑
    System.out.println(e.getMessage());
} finally {  // 可以省略
    // do sth;
}
```
### throws

将发生的异常抛出，交给调用者（方法）处理，最顶级的处理者就是JVM。

- 可以`throws`异常列表，或者异常父类；

- **编译异常**程序中必须处理，可以`try-catch`，也可以`throws`；

- **运行异常**程序中如果没有处理，默认`throws`（运行异常）；

- 子类继承父类，抛出的异常要么和父类一致，要么是父类异常的**子类**；

- `throws`过程中，如果有方法`try-catch`就相当于处理了，可以不用`throws`。

|**意义**|**位置**|**后面跟的东西**|
|---|---|---|---|
|**throws**|异常处理的一种方式|方法声明处|异常类型|
|**throw**|手动生成异常关键字|方法体中|异常**对象**|
