## Socket

套接字（Socket）开发网络应用被广泛采用，以至于成为事实上的标准。通信的两端都要有Socket，是两台机器间通信的端点，网络通信就是Socket间的通信。

Socket允许程序把网络连接当成一个流，数据在两个Socket间通过IO传输，一般主动发起通信的程序属于客户端，等待通信请求的为服务器。
```java
/*
客户端
  - 连接服务器
  - 连接服务器后生成Socket，通过getOutputStream写数据到数据通道
服务器
  - 在本机999端口监听，等待连接
  - 当没有客户端连接端口时，程序会阻塞，等待连接
  - 有连接时，通过getInputStream读取客户端写入到数据写数据，并显示
*/

// server
ServerSocket serverSocket = new ServerSocket(999);  // 在999舰艇，要求999不被占用
Socket socket = serverSocket.accept();  // 等待连接

InputStream inputStream = socket.getInputStream();// 被阻塞，没连接不执行
BufferedReader bufferedReader = new BufferedReader(InputStreamReader(inputStream));
String s = bufferedReader.readLine();  // 读取字符流
System.out.println(s);

OutputStream outputStream = socket.getOutputStream();
outputStream.write("hello, client".getBytes());  // 字节流
socket.shutdownOutput();  // 字节流结束标志

outputStream.close();  // 一般后打开的先关闭
bufferedReader.close();  // 关闭外层流
socket.close();
serverSocket.close();  // serverSocket可以创建多个socket

// client
Socket socket = new Socket(InetAddress.getLocalHost(), 999);  // 连接主机端口

OutputStream outputStream = socket.getOutputStream();
BufferedWriter bufferedWriter = new bufferedWriter(new OutputStreamWriter(outputStream));
bufferWriter.write("hello, server");  // 字符流
bufferWriter.newLine();  // 字符流结束标志，插入换行符，表示写入结束
bufferWriter.flush();  // 字符流需要手动刷新

InputStream inputStream = socket.getInputStream();
byte[] buf = new byte[1024];  // 读取字节流
int readLen = 0;
while ((readLen = inputStream.read(buf)) != -1) {

}

inputSream.close();
bufferedWriter.close();  // 关闭外层流
socket.close();
```
## DatagramSocket

UDP数据报通过数据报套接字DatagramSocket发送和接收，系统不保证UDP数据报一定能安全到达目的地，也不能确定什么时候到达；DatagramPacket对象封装了UDP数据报，在数据报中包含了发送端到IP地址和端口号，以及接收端的IP和端口。

UDP协议中每个数据报都给出了完整的地址信息，因此无须建立发送方和接收方的连接。UDP编程中没有明确的服务端和客户端，而是数据的发送端和接收端。
```java
// 建立发送端和接收端
// 建立数据包 DatagramPacket
// 调用 DatagramSocket 发送接收方法
// 关闭 DatagramSocket

// 接收端
DatagramSocket socket = new DatagramSocket(999);  // 在999接收数据

byte[] buf = new byte[64 * 1024];  // UDP一个包最大64K
DatagramPacket packet = new DatagramPacket(buf, buf.length);
socket.receive(packet);  // 有数据到999接收数据，把网络数据包填充到packet，否则阻塞

int len = packet.getLength();
byte[] data = packet.getData();
String s = new String(data, 0, len);  // 拆包，取出数据
System.out.println(s);

socket.close();

// 发送（接收）端
DatagramSocket socket = new DatagramSocket(998);  // 在998发送数据

byte[] byte = "hello".getBytes();
DatagramPacket packet = new DatagramPacket(byte, byte.length， InetAddress.getByName("192.168.1.12"), 999);  // 装包
socket.send(packet);

socket.close();
```
